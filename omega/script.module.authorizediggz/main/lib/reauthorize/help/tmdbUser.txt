TMDB account authorization[CR][CR]Choose Authorize / Upgrade TMDB Account in Tracking & Accounts. Scan the QR code with your phone, or choose Open in Browser on desktop Kodi. Sign in on the official TMDB website and approve access. Account Manager detects approval automatically, converts the V4 grant to a V3 session and synchronizes supported add-ons. No password is entered into Account Manager.[CR][CR]The QR code is generated locally and expires with the request token (15 minutes). Cancel preserves existing credentials.[CR][CR]Sync Addons sends V4 authorization to TMDb Helper and V3 to Diggz Portal. Existing V3-only accounts need to be upgraded once.[CR][CR]A TMDB metadata API key is separate from personal account authorization.
